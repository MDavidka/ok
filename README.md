# Cookie Clicker

A production-grade Cookie Clicker web game built with Vite, React, TypeScript, and Hero UI components.

## Features
- Click to earn cookies
- Upgrades that increase CPS
- Prestige/reset system with persistent multipliers
- Settings for sound and dark mode
- State persisted in session storage

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deployment
Deploy the `dist/` folder to Cloudflare Pages.
